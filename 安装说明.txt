============================================
  WPS AI Copilot 插件  安装说明（小白版）
============================================

这是一个装在 WPS 里的 AI 写作助手，装好后 WPS 顶部会多出一个
"AI Copilot" 按钮，点开右侧就能用 AI 帮你改写、续写、调字体段落格式。

--------------------------------------------
一、需要先装好的软件
--------------------------------------------
1. WPS Office（电脑上能正常打开 Word 文档即可）
2. Node.js  ：https://nodejs.org  （下载 LTS 版，一路下一步）
3. Python   ：https://www.python.org/downloads  （安装时务必勾选
              "Add Python to PATH"）

装完后，打开"命令提示符/PowerShell"，依次输入下面两行确认装好了：
    node -v
    python --version
能显示出版本号就说明 OK。

最后再装一个 WPS 开发工具（命令行里输入一次即可）：
    npm install -g wpsjs

--------------------------------------------
二、填入你自己的 DeepSeek 密钥
--------------------------------------------
1. 去 https://platform.deepseek.com 注册并获取 API Key
   （形如 sk-xxxxxxxxxxxxxxxx）

2. 把本文件夹里的：
      .env.development.example   复制一份，改名为   .env.development
      backend\.env.example       复制一份，改名为   backend\.env

3. 用记事本打开这两个新文件，把 your_deepseek_api_key_here
   替换成你自己的真实 Key，保存。

--------------------------------------------
三、启动（每次使用都要做）
--------------------------------------------
第 1 步：启动后端（命令行进入本文件夹后输入）
    cd backend
    pip install -r requirements.txt        ← 只有第一次需要
    uvicorn main:app --host 0.0.0.0 --port 8001
看到 "Application startup complete" 就成功了，这个窗口不要关。

第 2 步：另开一个命令行窗口，进入本文件夹，输入：
    npm install        ← 只有第一次需要
    wpsjs debug
它会自动打开 WPS。

第 3 步：在 WPS 顶部"wps加载项示例"选项卡里点 "AI Copilot"
        按钮，右侧出现聊天框即可使用。

--------------------------------------------
四、怎么用
--------------------------------------------
在文档里选中一段文字，然后在右侧聊天框输入，例如：
    帮我把这段润色得更书面一些       → 替换选中内容
    在后面补一段总结                 → 在光标处插入
    改成宋体小四号                   → 设置字体字号
    设置 1.5 倍行距，段前 6 磅       → 设置段落格式
    加粗并居中                       → 设置格式

--------------------------------------------
五、常见问题
--------------------------------------------
· 点了按钮没反应 / 报错：先确认第一步的后端窗口还开着、没报错。
· 提示连不上：确认 .env.development 里 VITE_COPILOT_API_URL 是
  http://localhost:8001（和后端端口一致）。
· AI 回复"出错了"：多半是 Key 没填对或 DeepSeek 账户余额不足。
